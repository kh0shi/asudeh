# ADR-0001: شناسهٔ پکیج `ir.asudehapp.sms`

- وضعیت: پذیرفته‌شده (D14)
- تاریخ: ۱۴۰۵/۰۶/۲۷

## زمینه
شناسهٔ پکیج بعد از اولین انتشار قابل تغییر نیست. تغییرش یعنی یک اپ جدید و از دست رفتن کاربران، امتیازها و نظرها. دامنهٔ `asudeh.ir` در اختیار دیگری است.

## تصمیم
- دامنه: `asudehapp.ir` (ثبت توسط مالک پروژه)
- Application ID: `ir.asudehapp.sms`
- پسوند `.sms` جا را برای اپ‌های احتمالی آینده (مثلاً `.calls`) باز می‌گذارد.

## پیامدها
- پیش از اولین انتشار باید دامنه ثبت شده باشد تا هویت پروژه قابل ادعا باشد.
- برای معرفی جهانی می‌توان بعداً دامنهٔ دیگری گرفت. شناسهٔ پکیج تغییر نمی‌کند.
