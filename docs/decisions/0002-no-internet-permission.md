# ADR-0002: اپ مجوز INTERNET ندارد

- وضعیت: پذیرفته‌شده (D2، D8، D12)

## زمینه
وعدهٔ اصلی «اطمینان خاطر» است. ادعای «داده‌ای ارسال نمی‌کنیم» را کاربر نمی‌تواند راستی‌آزمایی کند، ولی نبود مجوز INTERNET را می‌تواند (صفحهٔ مجوزهای فروشگاه، یا کد متن‌باز).

## تصمیم
`android.permission.INTERNET` در manifest نهایی وجود ندارد. CI این را با بررسی manifest ادغام‌شده (merged manifest) اجباری می‌کند، چون ممکن است یک کتابخانه بی‌صدا این مجوز را اضافه کند.

## پیامدها
- گزارش کرش، آمار و به‌روزرسانی قواعد از سرور ممکن نیست. قواعد فقط با آپدیت اپ به‌روز می‌شوند.
- گزارش خطا فقط با خروجی دستی و اشتراک‌گذاری توسط خود کاربر ممکن است.
- هر کتابخانهٔ جدید باید از نظر مجوزها بررسی شود.
